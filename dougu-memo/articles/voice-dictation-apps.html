音声入力アプリ4つを比べる

調査：2026年11月（各公式サイトの料金ページで確認）。料金はドル建ての月額・買い切り価格です。

話した言葉をその場で文章にしてくれる音声入力アプリ。OS標準の音声入力でも始まりますが、句読点の自動挿入や「えーと」の除去、アプリをまたいだ入力までやる専用アプリが増えています。代表的な4つを比べます。

比較表

アプリ対応OS処理無料枠有料プラン
Wispr Flow Mac / Windows / iPhone / Android クラウド 週2,000語まで Pro 月15ドル（年払い 月12ドル）
Superwhisper Mac / Windows / iPhone / Android ローカル／クラウド選択可 ローカルモデルは無制限 Pro 月8.49ドル、年84.99ドル、買い切り249.99ドル
VoiceInk Mac（Apple Silicon）/ iPhone ローカル（オープンソース） 試用あり 買い切り 25ドル（1台）〜49ドル（3台）
Aqua Voice Mac / Windows / iPhone クラウド 1,000語まで Pro 月12ドル（年払い 月10ドル）、Max 月24ドル

このほか、MacやWindowsに最初から入っている音声入力（無料）も選択肢です。まず標準機能で「声で書く」感覚を確かめてから、専用アプリに進むのが無駄のない順番です。

選び方

いろんな機械で使いたい → Wispr Flow

PCでもスマホでも同じアカウントで使えます。文章の整形（句読点、フィラー除去）まで自動で、対応言語は100以上。クラウド処理なので、ネットがない場所では使えません。

オフラインと買い切りがほしい → Superwhisper / VoiceInk

Superwhisperは手元の機械で認識するローカルモデルが選べて、無料枠でもローカル認識は無制限です。買い切りプランがあるのもこの2つ。VoiceInkはMac専用で、オープンソース、買い切り25ドルからと一番安く始められます。

技術用語や固有名詞が多い → Aqua Voice

独自の音声モデル「Avalon」を使い、専門用語寄りの聞き取りをうたっています。無料枠は1,000語と小さめなので、試して合うかどうかを見てから課金する形になります。

料金はいずれも2026年11月時点の公式表示です。プラン内容はよく変わるので、申し込む前に公式サイトで最新の条件を見てください。この記事は各アプリの公表情報をもとにした比較で、使用感のレビューではありません。
